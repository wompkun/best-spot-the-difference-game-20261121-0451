Twin Tales is a spot-the-difference game: two near-identical pictures side by side, seven changes hiding in each of three original procedurally-drawn scenes — a lantern-lit night market, a coral reef at blue hour, and an observatory on Mount Auralis. Find them all before the clock runs out, with limited hints, combo scoring, a keyboard cursor, and synthesized WebAudio sound effects. No build step, no network requests: plain static files under game/.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
